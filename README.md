## What this is

A reproducible audit of the Hugging Face dataset `lerobot/svla_so101_pickplace`
(50 real-world robot pick-and-place demonstrations), answering: *does this dataset's
recording structure support a naive frame-level train/test split, or does it require an
episode-level split to avoid leakage?* See `notebook/DS_A1_provenance_audit.ipynb`
Section 2 for the full question definition.

## How to run

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt --break-system-packages   # or without the flag in a venv
jupyter notebook notebook/DS_A1_provenance_audit.ipynb
```

Run every cell in order, top to bottom, on a clean kernel. The first code cell fixes
the random seed (42) and writes `environment_freeze.txt`. Section 4 resolves and prints
the dataset's exact commit SHA on first run — copy that value into
`data_card/SOURCE_LICENSE_HASH.md` and into the `PINNED_REVISION` variable so every
later run uses the frozen version.

## Exporting the PDF report

After a full clean run (so the saved outputs are current and real):

```bash
jupyter nbconvert --to pdf notebook/DS_A1_provenance_audit.ipynb \
  --output ../report/DS_A1_report.pdf
```

If `nbconvert --to pdf` fails because LaTeX is not installed, use the HTML fallback and
print to PDF from a browser:

```bash
jupyter nbconvert --to html notebook/DS_A1_provenance_audit.ipynb \
  --output ../report/DS_A1_report.html
```
